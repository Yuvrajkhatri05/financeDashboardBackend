💰 Finance Dashboard API

📄 For Full Documentation visit /api-docs

The Finance Dashboard system is developed with a strong emphasis on security, scalability, and efficient data management by incorporating a range of advanced backend features.

The application implements secure user authentication using JSON Web Tokens (JWT), which are stored in HTTP-only cookies to ensure safe session management and protection against common vulnerabilities such as XSS attacks.

It includes role-based authorization to control access to different resources and functionalities.

The system provides well-structured RESTful APIs for managing financial data, including income, expenses, and transaction records, with full support for CRUD operations.

Middleware is utilized for authentication, error handling, and request validation to maintain code modularity and reliability.

The backend is integrated with a MongoDB database for efficient storage and retrieval of data, ensuring high performance and scalability.

Additionally, features such as data validation, structured routing, environment-based configuration, and API documentation using Swagger enhance the robustness and maintainability of the system.

Overall, the project delivers a secure and efficient solution for managing and analyzing financial data.
